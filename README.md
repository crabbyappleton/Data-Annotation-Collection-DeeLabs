# Data Annotation Learning Journal

A practical notebook for collecting my data annotation lessons, study notes, terminology, exercises, and portfolio projects.

I'm using this repository to document what I learn as I work through data annotation training, including text annotation, named entity recognition (NER), image annotation, and related data skills.

## Repository guide

| Folder | What belongs here |
|---|---|
| [lessons/](lessons/) | Notes organized by course, module, or topic |
| [glossary/](glossary/) | Definitions of important annotation and data terms |
| [exercises/](exercises/) | Practice tasks, examples, and lessons learned |
| [portfolio/](portfolio/) | Polished sample projects that demonstrate skills |
| [resources/](resources/) | Useful websites, tools, tutorials, and references |
| [templates/](templates/) | Reusable lesson and note-taking templates |

## Suggested workflow

1. Save rough notes in the relevant lesson file.
2. Add unfamiliar terms to the glossary.
3. Keep practice exercises separate from polished portfolio samples.
4. Record what was challenging, what worked, and what I learned.
5. Revisit and improve earlier notes as my understanding grows.

## A note about examples and privacy

Use synthetic, public, or properly licensed examples in this repository. Do not upload private course material, personal information, confidential client data, or work that I do not have permission to share.
