# Portfolio Samples

This folder is for finished, shareable examples that demonstrate a skill—not simply raw course notes.

Potential projects:
- A small named entity recognition example
- A text classification sample
- An image classification or labeling example
- A short annotation quality review
- A data-cleaning example with a clear before-and-after explanation

For each sample, explain the goal, the annotation rules, the approach, and what the result demonstrates.

Use original, synthetic, public-domain, or properly licensed material. Never publish private client data or restricted course material.
