# Practice Exercises

Keep hands-on practice here. Include the task, the example data (only when it is safe to share), your result, and a short reflection.

For each exercise, note:
- What skill was practiced?
- What instructions or rules mattered?
- What mistakes or ambiguities came up?
- How would I improve the result next time?

Use synthetic or public examples. Do not include restricted course answers or confidential data.
